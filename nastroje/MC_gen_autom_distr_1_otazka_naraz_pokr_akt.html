Rýchly ťahák pre prírodné vedy:
  • Matematika:
    Zlomok: $$\frac{1}{2}$$  →  \(\frac{1}{2}\)
    Mocnina alebo horný index: $$x^2$$  →  \(x^2\)
    Dolný index: $$y_1$$  →  \(y_1\)
    Odmocnina: $$\sqrt{x}$$  →  \(\sqrt{x}\)
    Vyššia odmocnina: $$\sqrt[4]{625}$$  →  \(\sqrt[4]{625}\)
    Rovnica so zlomkom: $$x = \frac{-b}{2a}$$  →  $\displaystyle x = \frac{-b}{2a}$

  • Chémia:
    Chemický vzorec vody: \(\ce{H2O}\)  →  \(\ce{H2O}\)
    Chemická rovnica: \(\ce{H2SO4 -> 2H+ + SO4^2-}\)  →  \(\ce{H2SO4 -> 2H+ + SO4^2-}\)
